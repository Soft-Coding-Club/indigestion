# organ-A3 — 유리 형태 재설계 도착점 (2026-08-30)

「구토」 화면의 형태 방향. 유리 재료는 확정, 형태는 재설계.

## 핵심 개념 — 모어(母語)가 몸의 살이다

- 화면 전체 = 한국어 기념비가 **발광하는 조직(살)**. 소화된 말이 몸이 된다.
- 그 살을 뚫고 **어두운 식도(관)**가 세로로 지나간다. 가운데 잘록 = 삼키는 수축(연동).
- 관 속으로 **세상의 영어가 내려간다**. 하강할수록 흐려짐 = 소화가 하강 중 일어남.
- 관이 지난 자리 = 한국어가 파인 결손(아직 소화 안 된 자리).

## 왜 이 형태인가 (앞선 실패들이 답한 것)

- A1(유리병): 무지개 색분리 = 차가운 LED/표본병. 기각.
- A2(목구멍): 살은 됐으나 소화된 한국어가 벽 너머로 사라짐. 기각.
- A3: 개념 반전 — 벽=한국어(살), 관 속=영어(이물). 형태가 처음으로 의미와 붙음.
- 대비안 B(막): 오브제 소멸, 화면 전체가 젖은 유리. A로 확정.
